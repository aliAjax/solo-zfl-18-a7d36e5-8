# 桌游规则遗忘点卡片库 · 规则接力教练台

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒，并在聚会前把「谁来讲、按什么顺序讲」排成一场规则接力。

## 卡片库（原有功能）

- 按最近未玩、人数范围和复杂度筛选 / 排序 / 搜索
- 详情里展示聚会前快速复习卡片，可增删规则
- 标记今天玩过、删除桌游、封面上传
- localStorage 自动保存

## 规则接力教练台

每款桌游自动生成一份讲解接力计划，可完整自定义：

- **讲解顺序 + 必讲点 + 讲解人 + 前置关卡**：每个关卡一张卡，前置确认后才解锁下一关
- **插讲 / 补讲 / 跳过**：随时插讲到指定位置、把关卡放进补讲区（不占预算），跳过必须填写原因；前置关卡未确认前，后续关卡保持锁定（补讲区内的关卡同样受前置约束）
- **重排助手**：换人或压缩时间时只重排未确认关卡，锁定项与完成进度不动；超预算时给出可行方案（可选项建议跳过、必讲项转补讲区）
- **多人协作**：每个人编辑自己的草稿，合并前互不影响；可对比差异、确认合并、一键撤销、恢复历史草稿版本；多标签页同时编辑时自动合并各自草稿与进度，不会互相覆盖
- **导入导出**：导出全量数据为 JSON；导入时校验循环前置、重复关卡、缺失讲解人、时间冲突和失效引用，任何错误都会整单拒绝且不改原数据

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问（如 `python3 -m http.server`）。
